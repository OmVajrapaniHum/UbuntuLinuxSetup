# UbuntuLinuxSetup

Setup scripts for configuring Ubuntu 26.04:
- `s0010_fix_icons.sh`: Reinstalls and refreshes Adwaita and Yaru icon caches.
- `s0040_install_google_chrome.sh`: Installs Google Chrome (`amd64`) and configures its official APT repository.
- `s0050_install_vscode.sh`: Installs Visual Studio Code and Git via Microsoft's APT repository.
